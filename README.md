# SoundPulse Desktop - Local Music Player 🎵

**SoundPulse Desktop** là ứng dụng nghe nhạc cá nhân chuyên dụng trên máy tính (PC Windows/Mac), được xây dựng bằng Electron, Web Audio API, HTML5 Canvas và CSDL IndexedDB.

## ✨ Tính Năng Nổi Bật Trên Desktop

- 🎧 **Phát Nhạc Local Siêu Tốc**: Hỗ trợ các định dạng nhạc phổ biến (`.mp3`, `.wav`, `.flac`, `.ogg`, `.m4a`, `.aac`).
- 📁 **Kéo Thả & Chọn Thư Mục Nhạc**: Tự động gom nhóm bài hát và tạo ngay một Playlist tương ứng với tên thư mục.
- 🔂 **Chế Độ Lặp Bài Hát Linh Hoạt**: Phát ngẫu nhiên (Shuffle), Lặp lại tất cả, hoặc **Chỉ lặp lại 1 bài hát (Repeat Single Track)**.
- 🎚️ **Equalizer 10 Dải & Visualizer 3D Neon**: Bộ lọc dải âm tần chi tiết và sóng nhạc visualizer 3D chân thực.
- 📋 **Đổi Kiểu Hiển Thị (Grid / List View)**: Tùy chọn hiển thị dạng thẻ ảnh bìa hoặc dạng hàng ngang rút gọn.
- 💾 **Lưu Trữ CSDL Offline (IndexedDB)**: Tất cả Playlist và nhạc được lưu an toàn trên máy tính.

## 🚀 Hướng Dẫn Chạy & Build App

### 1. Cài đặt các thư viện
```bash
npm install
```

### 2. Khởi động app ở chế độ phát triển
```bash
npm start
```

### 3. Đóng gói ra file cài đặt Windows (.exe)
```bash
npm run build:win
```
